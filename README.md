# 个税与个人养老金抵扣计算器

基于 **Rust + eframe/egui** 的 Windows 桌面应用，用于测算个人所得税与个人养老金缴费的抵税效果，并给出最省税的缴费方案与长期收益。

## 功能

1. **个税计算** — 按综合所得年度 7 级超额累进税率表，由应纳税所得额算出应缴个税
2. **月收入换算** — 支持直接输入税前月收入，自动扣除五险一金、补充公积金与基本减除费用后换算应纳税所得额
3. **退税计算** — 个人养老金缴费（年上限 12,000 元）税前据实扣除，计算少缴的税额
4. **最优缴费额** — 在 0 ~ 12,000 元范围内求解「退税收益 − 领取税成本」最大化的缴费额
5. **长期收益测算** — 按缴纳年限累加，计算一次性领取时的最终收益
6. **净收益曲线** — 可视化「缴费额 → 单年净收益」，并标注最优缴费点

## 两种收入输入方式

界面顶部可切换：

- **直接填应纳税所得额** — 你已有扣除后的金额，直接录入
- **填税前月收入（自动换算）** — 录入税前月收入，程序按下列公式换算：

```
年应纳税所得额 = 税前月收入 × 12 − 60000(基本减除) − 年五险一金及补充公积金个人缴存额
```

### 五险一金配置（月收入模式）

可在「五险一金 / 补充公积金缴纳比例设置」面板中调整各险种**个人**缴存比例：

| 项目 | 默认比例 | 说明 |
| --- | --- | --- |
| 养老保险 | 8% | 个人缴存部分 |
| 医疗保险 | 2% | 个人缴存部分 |
| 失业保险 | 0.5% | 个人缴存部分 |
| 住房公积金 | 7% | 常见区间 5%~12% |
| 补充公积金 | 0% | 部分地区 / 单位有，0%~8% |

> 工伤、生育保险由**单位**全额缴纳，个人不缴，故不列入。

**缴费基数**：可在面板中设置上下限（默认 3,000 ~ 35,000 元/月）。月收入低于下限按下限缴，高于上限按上限缴（自动封顶）。

**分项金额展示**：配置面板中每个险种的**右侧直接显示该险种对应的月缴存额与年缴存额**，调整比例或月收入时实时刷新，边调边看。

面板布局如下（金额随输入实时变化）：

| 项目 | 个人比例 | 月缴存（元） | 年缴存（元） |
| --- | --- | --- | --- |
| 养老保险 | 8.000% | 1,600.00 | 19,200.00 |
| 医疗保险 | 2.000% | 400.00 | 4,800.00 |
| 失业保险 | 0.500% | 100.00 | 1,200.00 |
| 住房公积金 | 7.000% | 1,400.00 | 16,800.00 |
| 补充公积金 | 0.000% | 0.00 | 0.00 |
| **合计** | **17.500%** | **3,500.00** | **42,000.00** |

*(示例：月收入 20,000 元、默认比例)*

> 上表数值均以「缴费基数」为计算依据，基数受上下限约束。

## 计算口径

- **应纳税所得额**：直接模式下你输入的即为已扣 6 万元基本减除费用及三险一金等专项扣除后的金额；月收入模式下由程序自动换算
- **个税公式**：`应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数`
- **退税**：`退税 = 未缴时的个税 − 缴费后的个税`（缴费使应纳税所得额下降）
- **领取环节**：个人养老金领取时按单一税率计税，**默认 3%**，可自定义
- **最终收益** = `一次性领取到手金额 + 累计退税 − 累计实缴本金`（**不计投资收益**）


### 税率表（综合所得年度）

| 级数 | 应纳税所得额（元） | 税率 | 速算扣除数 |
| --- | --- | --- | --- |
| 1 | 不超过 36,000 | 3% | 0 |
| 2 | 36,000 ~ 144,000 | 10% | 2,520 |
| 3 | 144,000 ~ 300,000 | 20% | 16,920 |

| 7 | 超过 960,000 | 45% | 181,920 |

## 运行

```bash
cargo run --release
```

生成的程序位于 `target/release/tax-calculate.exe`，双击即可运行（**不会弹出控制台窗口**）。

> 界面采用护眼灰白配色（浅暖灰底 + 深色文字），减轻长时间使用的视觉疲劳。
> debug 构建会保留控制台便于查看日志，release 构建自动隐藏。
